## Panduan Menjalankan Proyek

1. **Pengecekan Kesiapan Environment:**
   ```bash
   flutter doctor
   ```

2. **Navigasi ke Direktori Proyek Tertentu (contoh Minggu 1):**
   ```bash
   cd 01-week-1-mobile-development-ecosystem-flutter-refresh/my_first_app
   ```

3. **Instalasi Dependensi:**
   ```bash
   flutter pub get
   ```

4. **Eksekusi Aplikasi:**
   ```bash
   flutter run
   ```
